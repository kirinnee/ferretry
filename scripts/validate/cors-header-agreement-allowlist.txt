#
#   unadmitted  the browser code can send it and the preflight refuses it. A shipped dead route.
#               A line here is a defect being recorded, not a decision being made.

#               caller is the only sender, because CORS never applies to one.

# set in advance of a sender: that is the wish-list failure this gate exists to prevent, and the same
# rule `route-agreement-allowlist.txt` holds its own unreached routes to.
