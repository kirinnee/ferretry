Get started

One command to your fleet

Install Ferretry where Claude Code or Codex runs, then run fy setup. It starts the daemon, checks it, and shows a QR code for your phone.

Rather have your agent do it? Copy the prompt — it hands you each command to run.

  • Latest release v%FY_RELEASE_VERSION%
  • macOS on Apple silicon · Linux amd64 / arm64
  • Needs Claude Code or Codex, and tmux

  1. Step 01

    Install it, then run setup.

    Pick how you install software. The tab for this device is chosen for you. Each one ends with fy setup, which starts the daemon as a user service, checks it, and offers the QR code for your phone.

    Safe to run again: it leaves a running daemon alone.

    Homebrew

    Homebrew · macOS
    brew tap kirinnee/ferretry https://github.com/kirinnee/ferretrybrew install --cask ferretryfy setup

    The cask clears macOS's quarantine flag for you, so the first run just works.

    Nix profile

    Nix · macOS or Linux 
    nix profile install github:kirinnee/ferretryfy setup

    Updates with fy daemon update, no config to edit.

    Home Manager or nix-darwin

    Add to your flake
    inputs.ferretry.url = "github:kirinnee/ferretry";home.packages = [ inputs.ferretry.packages.${pkgs.stdenv.hostPlatform.system}.default ];
    Then rebuild
    home-manager switch --flake .fy setup

    On nix-darwin, rebuild with darwin-rebuild switch --flake . instead. Updating means bumping the flake input, because your config owns the version.

    Installer

    Any Mac or Linux
    curl -fsSL --connect-timeout 30 --max-time 600 https://github.com/kirinnee/ferretry/releases/latest/download/install.sh | bashPATH="$HOME/.local/bin:$PATH" fy setup

    It checks the download and puts both programs in ~/.local/bin; add that to your PATH.

    Debian, Ubuntu or Fedora package? Every option is in INSTALLATION.md; run fy setup after any of them.

    Or let your agent do it.

    Paste this into Claude Code or Codex on the computer you want to use. It looks around, recommends one way to install, and hands you each command to run. It never installs anything itself, so its safety checks never get in the way.

  2. Step 02

    Pair your phone.

    fy setup offers this at the end. To pair later, or another phone, run this and scan the QR code with your phone's camera. The code lasts two minutes and works once.

    Your phone does not need to be on the same network. When it cannot reach the computer directly, it connects through Ferretry's end-to-end encrypted relay, which never sees the code or anything you send.

    On your computer
    fy pair
    Pairing over SSH, or at this computer

    Run these in your own terminal, never through an agent: the code is a live key to this computer. fy pair waits up to two minutes for the scan. Add --no-wait to print the QR code and link and exit instead; add --open too when you are sitting at this computer, to hand the link to its browser.

    At this computer
    fy pair --open --no-wait
    Over SSH or from a script 
    fy pair --no-wait

    No password to set: your phone registers a passkey, and risky actions ask for it later.

  3. Step 03

    Finish setup in the app.

    Once your phone is paired, the app opens setup by itself. Every step can be skipped and changed later in Settings.

    • Claude Code and Codex — use your existing login and setup
    • Keys — add logins and providers; keys go in the secret store
    • Voice — on-device dictation, with optional clean-up
    • Warden — what watches your sessions, and how much it may spend

Troubleshooting

If something is off.

  • Check everything.

    Daemon, version, updates and the relay, changing nothing.

    Check
    fy setup --check

  • Is the daemon running?

    Says whether it is serving, and what started it.

    Status
    fy daemon status

  • What went wrong?

    Prints the daemon's log.

    Logs
    fy daemon logs

  • macOS says it can't open fy.

    The programs are not code-signed. Homebrew handles this; after any other install, clear the quarantine flag once.

    macOS
    xattr -d com.apple.quarantine "$(command -v fy)"

  • Start over completely.

    Removes ALL Ferretry data on this computer: settings, sessions, stored secrets and paired devices. It lists what will go and asks before it deletes anything.

    Reset
    fy daemon reset
