Get started

Four steps to your fleet

Set up a new computer: install Ferretry where Claude Code or Codex runs, start its daemon, and pair your phone. About five minutes.

Rather not type? Let your agent set it up with one prompt.

  • Latest release v%FY_RELEASE_VERSION%
  • macOS on Apple silicon · Linux amd64 / arm64
  • Needs Claude Code or Codex, and tmux

  1. Step 01

    Install it on your computer.

    This installs the fy command and the fyd daemon. Pick your system — the tab for this device is chosen for you.

    macOS

    Homebrew
    brew tap kirinnee/ferretry https://github.com/kirinnee/ferretrybrew install --cask ferretry

    The cask clears macOS's quarantine flag for you, so the first run just works.

    Linux

    Debian / Ubuntu
    echo "deb [trusted=yes] https://apt.fury.io/kirinnee97/ /" | sudo tee /etc/apt/sources.list.d/fury.listsudo apt updatesudo apt install fy
    Fedora / RHEL
    sudo tee /etc/yum.repos.d/fury.repo <<'EOF'[fury]name=Gemfury kirinnee97baseurl=https://yum.fury.io/kirinnee97/enabled=1gpgcheck=0EOFsudo dnf install fy

    Nix

    Install
    nix profile install github:kirinnee/ferretry
    Or try it without installing 
    nix shell github:kirinnee/ferretry

    Works on macOS and Linux. The daemon pins its own Nix store path, so garbage collection cannot remove it.

    Any Mac or Linux: one-line installer 
    curl -fsSL --connect-timeout 30 --max-time 600 https://github.com/kirinnee/ferretry/releases/latest/download/install.sh | bash

    It checks the download and puts both programs in ~/.local/bin. Every option is in INSTALLATION.md.

    Or let your agent set it up.

    Paste this into Claude Code or Codex, in a terminal on the machine you want to use. It follows the tab you picked (), runs steps 1 to 3 for you, and stops so you can scan.

  2. Step 02

    Start the daemon.

    The daemon is the part that runs your sessions. This installs it as a user service (launchd on macOS, systemd on Linux), starts it, and brings it back after a restart.

    On your computer
    fy daemon install

  3. Step 03

    Pair your phone.

    Run this, then scan the QR code with your phone's camera. The code lasts two minutes and works once.

    Your phone does not need to be on the same network. When it cannot reach the computer directly, it connects through Ferretry's end-to-end encrypted relay, which never sees the code or anything you send.

    On your computer
    fy pair
    Pairing from a script or an agent

    fy pair waits up to two minutes for the scan. Add --no-wait to print the QR code and link and exit instead; add --open too when you are sitting at this computer, to hand the link to its browser.

    At this computer
    fy pair --open --no-wait
    Over SSH or from a script 
    fy pair --no-wait

    No password to set: your phone registers a passkey, and risky actions ask for it later.

  4. Step 04

    Finish setup in the app.

    Once your phone is paired, the app opens setup by itself. Every step can be skipped and changed later in Settings.

    • Claude Code and Codex — use your existing login and setup
    • Keys — add logins and providers; keys go in the secret store
    • Voice — on-device dictation, with optional clean-up
    • Warden — what watches your sessions, and how much it may spend

Troubleshooting

If something is off.

  • Is the daemon running?

    Says whether it is serving, and what started it.

    Status
    fy daemon status

  • What went wrong?

    Prints the daemon's log.

    Logs
    fy daemon logs

  • macOS says it can't open fy.

    The programs are not code-signed. Homebrew handles this; after any other install, clear the quarantine flag once.

    macOS
    xattr -d com.apple.quarantine "$(command -v fy)"

  • Start over completely.

    Removes ALL Ferretry data on this computer: settings, sessions, stored secrets and paired devices. It lists what will go and asks before it deletes anything.

    Reset
    fy daemon reset

Open the app and go to your machines. This guide is only for a computer that has no Ferretry yet: to add another one, run steps 1 to 3 on it.
