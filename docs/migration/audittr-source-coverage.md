deliberately a capability map rather than a filename comparison: the migration
split each kteam monolith into parser, source, analytics, storage, and mounting
modules.

## Blocking chain and next coherent slice

`DaemonWorld.transcripts` is correctly constructed but currently unreachable from a
session because `TranscriptSource.read(file)` needs an exact file and session
documents record neither file nor discovery evidence. That same missing evidence
leaves migration's tool inventory fail-closed, leaves `lastTranscriptAt`
unwritten, and prevents learning extraction from naming its source.

The next implementation slice must therefore be a session-owned transcript
provenance record: persist the wrapper-resolved harness home and harness session
identity at creation, derive Claude's deterministic path, and discover Codex only
against a pre-launch baseline plus injected-session correlation. Only after that
record exists should the generic follower be mounted, then usage ingestion can
consume its exact source without silent cross-session data loss.
